# ZAOstock Pitch Pack - the one place

Everything a teammate or partner agent needs to pitch ZAOstock, in one directory.
Facts follow `src/content/festival.ts` and its locked publication rules (no
performer names, no date other than Oct 3 on public surfaces).

| File | What | Consumes it |
|---|---|---|
| `pack.json` | Machine-readable facts, stats, tiers, confirmed partners, links | Agents (ZOE, partner agents via the ZAO bus), the site |
| `deck-words.md` | The sponsor deck words, three variants (general / local / online) | Paper + Candy (design), anyone pitching |
| this README | Index + status | Humans |

## Status (2026-08-20)

- Deck words: v1 complete, seven decisions open with Zaal (ZAOOS doc 2325).
- Confirmed public partners (matches the live site): Black Moon, Star 97.7,
  Wallace Events, WaveWarZ. Heart of Ellsworth is the venue host; their branding

  deliberately does NOT live in this public repo. It lives in ZAOOS research
  (docs 2325, 2326) and reaches partner agents over the token-gated ZAO bus.
